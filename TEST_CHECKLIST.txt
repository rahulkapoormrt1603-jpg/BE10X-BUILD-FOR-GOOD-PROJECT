CURL COMMANDS FOR MANUAL TESTING
=================================

# Health check
curl http://localhost:5000/health

# Valid upload (replace with actual video file)
curl -X POST http://localhost:5000/analyze -F "file=@test-video.mp4"
curl -X POST http://localhost:5000/analyze -F "video=@test-video.mp4"

# Error cases
curl -X POST http://localhost:5000/analyze
curl -X POST http://localhost:5000/analyze -F "file=@document.txt"
curl -X POST http://localhost:5000/analyze -F "file=@/dev/null;filename=empty.mp4"

# PDF downloads
curl -O -J http://localhost:5000/download-guide/minimal
curl -O -J http://localhost:5000/download-guide/mild
curl -O -J http://localhost:5000/download-guide/severe
curl -X GET http://localhost:5000/download-guide/invalid

# Verbose debugging
curl -v -X POST http://localhost:5000/analyze -F "file=@test-video.mp4"

SEVERITY CATEGORIES
===================
- minimal: score < 40
- mild: 40 <= score < 70
- severe: score >= 70
